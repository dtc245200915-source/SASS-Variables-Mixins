# Thực hành SASS Variables & Mixins

Bài thực hành tối ưu CSS bằng SASS theo đúng yêu cầu:
- Variables
- Mixins
- Tách SCSS thành partials
- Áp dụng mixins cho button và card

## Cấu trúc
- `scss/abstracts/_variables.scss`
- `scss/abstracts/_mixins.scss`
- `scss/base/_typography.scss`
- `scss/components/_buttons.scss`
- `scss/components/_cards.scss`
- `scss/main.scss`
- `css/style.css`

## Biên dịch
```bash
sass scss/main.scss css/style.css
```

Chế độ watch:
```bash
sass scss/main.scss css/style.css --watch
```
